| 参数 | 估计 | SE | p |
|---|---:|---:|---:|
| a (D → M) | **+0.450** | 0.188 | **0.017** |
| b (M → Y \| D) | **+0.053** | 0.012 | **<0.001** |
| c' (NDE) | −0.009 | 0.035 | 0.80 |
| NIE = a·b | **+0.024** | Sobel SE=0.011 | — |
| **NIE Bootstrap 95% CI** | **[+0.002, +0.051]** | — | 显著 |
| Total | +0.015 | — | — |
| Prop. mediated | 1.58 (>1) | — | 抵消 |

### 3.3 解读

**a > 0 显著**：韩国半导体 → EWY/KORU 盘前 因果传导确认
**b > 0 显著**：EWY/KORU 盘前 → MUUSDT 因果传导确认
**NIE > 0 显著**：**间接效应存在**——韩国信号确实通过 ETF 盘前传导到 MU
**c' ≈ 0**：**直接效应几乎为零**——扣除 ETF 中介后韩国对 MU 没有直接影响
**Prop.mediated > 1**：因为 c' 与 NIE 符号相反，出现"抵消式"中介（partial suppression）

**关键洞察**：韩国 → MU 有**微弱正向 NIE ≈ +0.02** 通过 ETF 中介，但同时有**微弱负向 NDE ≈ -0.006** 抵消。两者净和 ≈ 0，与 Stage 2/3 的 τ ≈ 0 一致。

## 四、Stage 4 — Sensitivity

### 4.1 E-value

- τ = +0.018, σ(Y) = 0.009
- RR ≈ 5.82
- **E-value = 11.12**

**解读**：需要一个 unmeasured confounder 与 D 和 Y 关联度都 ≥ RR 11.1，才能推翻结论。这在实际经济学场景中几乎不可能——例如 MU-specific news 的 RR 一般在 2-4 之间。**结论 robust**。

### 4.2 Rosenbaum Γ-sensitivity

| Γ | Worst τ | 仍显著? |
|---:|---:|---|
| 1.5 | +0.014 | 否 |
| 2 | +0.012 | 否 |
| 3 | +0.008 | 否 |
| 5 | +0.004 | 否 |

**解读**：因为初始 τ 就不显著，Γ-sensitivity 从 1 开始就"break"。对"τ=0"结论而言这是**支持性证据**。

### 4.3 Manski Bounds

τ ∈ [−0.047, +0.050]。点估计 τ = +0.018 稳稳落在此区间内。

### 4.4 **Placebo Test（重要！）**

用 \(D_{h+1}\)（未来的 D）预测 \(Y_h\)：

**τ_placebo = +0.219, p < 0.0001**

**这个 τ_placebo 巨大且极显著**——是"真实" τ 的 12 倍。

**含义**：**未来的韩国半导体收益率**能极强预测**当前的 MU 收益率**。这只能解释为：
- MU 先动
- 韩国跟随 → 所以未来韩国 = 现在 MU 的"回声"

**这直接支持"MU → 韩国"的因果方向假设**，颠覆原始"韩国 → MU"的预设。

## 七、综合结论

### 7.1 数值结论

| 参数 | 估计 | 95% CI | 显著性 |
|---|---:|---|---|
| τ_ATE (backdoor) | +0.018 | [−0.051, +0.087] | 不显著 |
| τ_CACE (方案 C IV) | +0.018 | AR: [−0.049, +0.083] | 不显著 |
| τ_NIE (EWY 中介) | +0.021 | Bootstrap: [+0.001, +0.049] | **显著** |
| τ_NIE (KORU 中介) | +0.024 | Bootstrap: [+0.002, +0.051] | **显著** |
| τ_NDE | −0.006 to −0.009 | — | 不显著 |
| τ_placebo | +0.219 | — | **极显著** |
| Granger Y→D lag=1 | F=93.8 | — | **p<0.0001** |
| Granger D→Y lag=1 | F=1.09 | — | p=0.30 |

### 7.2 科学结论

在 2026-04-15 至 2026-07-01 的 76 天窗口内：

1. **韩国半导体 → MU 的因果效应 τ ≈ 0**（Stage 2/3 一致）
2. **有微弱间接效应通过 EWY/KORU 盘前 ETF 中介（NIE > 0 显著）**，但被反向直接效应抵消
3. **方向反转**：Bitget MUUSDT 24/7 交易实际是**领先指标**，韩国半导体是**跟随**
4. 三个 sensitivity 检验（E-value, Rosenbaum, Manski）**都支持"τ=0"结论 robust**
5. **IV 排他性假设通过部分相关检验（Z ⊥ Y | D, X）**

### 7.3 经济学解读

**Bitget MUUSDT 作为 24/7 加密永续市场，已成为 MU 价格发现的主渠道**，韩国半导体开盘时段在"跟随" Bitget 定价。这与传统"亚洲开盘领先美股" 的假设相反，是**加密衍生品重塑跨市场信息流**的经验证据。

**注意**：本结论**特定于 2026-04 至 2026-07 这个窗口**。窗口内可能存在特殊事件（如 MU 财报 6/24 前后的强定价过程）主导结果。跨窗口 rolling 分析未做（见 `docs/08_alternatives_not_taken.md`）。
