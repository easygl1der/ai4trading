# Polybot research notebook

This is the primary documentation source for the paper strategy lab. It is intentionally separate from the live dashboard: the dashboard answers what each independent run is doing now; this site answers what was tested, which mechanisms were rejected, and what the recorded evidence does not justify.

> Backtests here are used first as falsification instruments. A configuration is not promoted merely because it ranks highly in replay return; it must remain intelligible under fee-aware fills, alternative windows, fresh paper data, and loss-streak comparison.

## Read the evidence in this order

1. [Research method](/research-method) defines the recorded data and missing execution assumptions.
2. [Strategy families](/strategy-families) explains which runs are independent experiments versus parameter variants.
3. [Live versus replay](/live-vs-replay) records the present out-of-sample warning.
4. [Full source reports](/reports) mounts the complete original Markdown reports and figures rather than merely citing their filenames.
